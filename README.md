# VELU bottle demo

A static product page for a fictional UV-C smart bottle. The layout and scroll-driven motion follow a short product film; the brand, copy, logo, and 3D bottle are invented.

Live: https://josekb-arch.github.io/velu-bottle-demo/?v=1

Open `index.html` from a local server (GitHub Pages, or `python3 -m http.server`) so the ES modules load.
