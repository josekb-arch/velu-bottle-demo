# Credits

This page is an original demo inspired by the layout and scroll motion of a product film. It does not use that brand's name, photos, 3D files, typography, or other assets.

VELU is a fictional hydration brand invented for this demo. The bottle, copy, logo, and product claims are invented and are not for sale.

## 3D

The bottle, cap, interior, lights, and icon sprites are built in code (lathe geometry, canvas textures, and procedural meshes). No third-party product model or studio file was used. Studio lighting uses Three.js `RoomEnvironment`.
